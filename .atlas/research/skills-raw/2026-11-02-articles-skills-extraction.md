## Themes

**#1 Medium - "6 Skills That Make Claude Code and Codex Better at SwiftUI" (Shubham Singh, Sep 9 2026)**
- Framed around AI "house style" / "AI slop" on iOS (unstyled List, uniform .body fonts, flat backgrounds, Settings-app look); the skills are split into ones that make the agent write better SwiftUI and ones that critique design and hand back code.
- Cross-tool portability: "almost none of these are locked to one tool. They use the open Agent Skills format, so the same skill drops into Claude Code, Codex, Cursor, Gemini, and others" (author uses Codex for architecture/logic, Claude Code for design/UI).
- Safety and discipline: "Every skill you install runs with real access to your machine ... Read what a skill does before you add it"; install one at a time (SwiftUI Pro first), avoid context bloat; the author deliberately omits star counts because quoted counts "didn't hold up".
- Assumes current tooling: SwiftUI Pro "built for iOS 26 and later and Swift 6.2 and later"; SwiftUI Expert leans on iOS 26+ Liquid Glass and keeps a deprecated-API reference fresh "after new iOS or Xcode releases". Closing point: a skill "doesn't give you taste".
