# Competitor feature lists (fetched 2026-11-03)

Note: store pages were fetched via summarizing WebFetch; counts/ratings are as shown on the date above. Chrome Web Store pages show no price (all free to install).

## Enhancer for YouTube
- Source: https://chromewebstore.google.com/detail/enhancer-for-youtube/ponfpcnoihfmfllpaingbgckeeldkhle ; https://www.mrfdev.com/enhancer-for-youtube ; https://www.mrfdev.com/how-to-use-enhancer-for-youtube
- Price: not stated (free to install). Rating 4.5/5 (17.6K ratings). Users: 1,000,000.
- Features:
  - Playback speed via mouse wheel or keyboard; default speed; range 0.07x-16x; finer steps than YouTube (e.g. 1.1, 1.15); three speed controls for non-mouse users
  - Default playback quality (videos, playlists, embeds), auto-selected on load
  - Volume via mouse wheel; Volume Booster up to 10x
  - Default volume / speed / quality also applied to embedded videos (https embeds only)
  - Enhanced Loop Mode (part or whole video; numeric fields adjustable by wheel or up/down buttons)
  - Autoplay control (disable; prevent background-tab autoplay; stop videos fully to save bandwidth)
  - Disable high frame rate (force 24/25/30 FPS instead of 48/50/60)
  - Force MP4 + AVC (H.264) instead of WebM/VP9
  - Video filters (brightness, contrast, colour, etc.; flip video)
  - Enhanced Dark Mode (50+ variants), custom themes (custom CSS, accent colour on scrollbars), custom script
  - Cinema Mode (dims surroundings; exit with Esc or click outside)
  - Wide / larger player (beyond Theater Mode, or fill window without fullscreen)
  - Mini Player (auto-launch on scroll to read comments; subtitles draggable, need >=560x315)
  - Resizable Pop-up Player (can be pinned on top; needs youtube-nocookie.com permission in v3.0)
  - Picture-in-Picture button toggle via theme
  - Hide end screens, info cards, recommendations, related videos, chat, comments
  - Hide Shorts or watch them as regular videos
  - High-quality screenshots (quality depends on playback quality/size)
  - Reverse playlist order
  - Customizable keyboard shortcuts for almost all features (assigned in browser shortcut settings; no defaults listed)
  - Mouse shortcuts: Ctrl+click video = default speed; Ctrl+Shift+click = 1x; wheel on embeds = speed/volume
  - Focus returns to player after using progress/volume bars so native shortcuts work
  - Info icons in options page explaining click / right-click actions
  - Settings backup recommended; pin toolbar icon
  - Known limits: no "1080p Premium" selection; booster can mute avc1+mp4a.40.2 until reload; wheel conflicts with Logitech Smooth Scrolling; flip not in fullscreen with HW accel
  - YouTube native shortcuts (Space, arrows) still work; page does not list control button names or default key bindings

## YouTube Enhancer
- Source: https://chromewebstore.google.com/detail/youtube-enhancer/dejhhgdpambaambdifcfbmpliolehfaj
- Price: not stated (free). Rating 4.4/5 (16 ratings). Users ~2,000.
- Features:
  - Default playback speed with on-screen controls
  - Default video quality (e.g. 1080p, 4K)
  - Mouse wheel controls speed or volume
  - One-click video loop
  - Global volume level; separate volume memory for Shorts vs regular videos
  - Volume boost beyond YouTube limit
  - Skip "Video paused? Continue watching?" prompt
  - Auto-pause videos in background tabs
  - Auto Theater Mode / maximize player
  - Quick access to transcripts
  - Remove redirect links and tracking parameters from URLs
  - Screenshots in multiple formats
  - Extra dark themes (Dracula, Solarized), custom colours, custom CSS
  - Resume where you left off
  - Hide live chat, Shorts, end-screen cards, other small UI tweaks
  - Open source (MIT)

## Improve YouTube! (for YouTube & Videos)
- Source: https://chromewebstore.google.com/detail/improve-youtube-%F0%9F%8E%A7-for-yo/bnomihfieiccainjcjblhegjgglakjdd
- Price: not stated (free). Rating 4.4/5 (7.2K ratings). Users 400,000. Claims "170+" (also "85+") features.
- Features:
  - Extra player buttons: loop, rotate, screenshot
  - Custom keyboard shortcuts
  - Fixed default playback speed
  - Volume mixer; loudness normalization
  - Auto-pause, auto-fullscreen
  - Theater and window expansion; player resizing
  - Mini player, popup, pop-out player
  - Default video quality; frame-rate and HDR/SDR preference; prefer H.264
  - Block videos, channels, tags or categories
  - Remove related videos; hide comments, live chat, annotations, video details
  - Ad blocker (optional allow for subscribed channels)
  - Themes with dark-mode scheduling; OLED black theme
  - Blue-light filter; display dimming; focus mode (dims page until hover)
  - Undo new sidebar
  - Activity analytics
  - Playlist reverse and shuffle
  - Frame-by-frame viewing
  - Always-expanded description, transcripts, chapters
  - Subtitle options
  - "Virtual Travel" (change content country)
  - Autoplay controls
  - Embedded-video features also on Facebook, mobile YouTube, Netflix, Twitch, Vimeo

## Clean YT for Safari
- Source: https://apps.apple.com/us/app/clean-yt-for-safari/id6754407661
- Price: $2.99. Rating 5.0 (1 rating). Developer Alfredo Grassau.
- Platforms: both (iOS 15+, iPadOS 15+, macOS 12+, also visionOS).
- Features:
  - Removes Shorts from feeds
  - Filters sponsored videos
  - Hides comments
  - Hides suggested videos
  - No data collection / tracking
  - Multiple languages
  - Streamlined UI

## SponsorBlock for Safari
- Source: https://apps.apple.com/us/app/sponsorblock-for-safari/id1573461917
- Price: $2.99. Rating 4.4 (81 ratings).
- Platforms: both (iOS 15+, iPadOS 15+, macOS 11+, also visionOS).
- Features:
  - Skips sponsor segments via crowdsourced timestamps
  - Skips intros, outros, subscription reminders, other non-content
  - Skips non-music sections of music videos
  - Open source, public database
  - Random user ID for submissions, voting, leaderboard
  - Does not block regular ads (suggests AdGuard)
  - YouTube website only, not the app

## PocketTube for Safari
- Source: https://apps.apple.com/us/app/pockettube-for-safari/id1533703891?mt=12
- Price: Free (no IAP shown). Rating: none displayed (not enough ratings).
- Platforms: macOS only (macOS 10.14+); mentions auto-sync on iOS.
- Features:
  - Topic-based groups of channels (collections)
  - One subscription in multiple collections
  - Custom icons for collections
  - Latest videos per collection, playable as a playlist
  - Auto-sync collections on iOS
  - Integrates in YouTube home page and left tab
  - Filter feed by topic
  - Hide watched videos; search on feed page
  - Sort by activity, A-Z, subscription count, custom
  - Catch up on subscriptions

- Platforms: both (iOS 15+, iPadOS 15+, macOS 11+, also visionOS).
