# Support

Questions, bugs and ideas: xkmtrx@gmail.com. Say which device and Safari version you use and what you expected to happen. The Support page inside the extension's settings fills in the version and device for you.

## Turning the extension on

- iPhone and iPad: open the app once, then Settings > Apps > Safari > Extensions, turn the extension on, and allow it on youtube.com the first time Safari asks.
- Mac: open the app once, then Safari > Settings > Extensions, tick the extension, and allow youtube.com from the toolbar button.

## Common questions

- **Something looks wrong on YouTube.** Turn the extension off in Safari's extension settings and reload. If the page is fine without it, write in with the setting you had on.
- **A setting does nothing.** YouTube changes its page often. Write in with the video link and the setting; fixes ship as updates.
- **Where are my settings?** On the device, in the extension's own storage. Export and Import in the settings move them between devices.
- **Does it block ads?** No.
- **Does it download videos?** No, and it will not.
